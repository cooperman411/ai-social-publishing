# Optional route: Buffer MCP / API

A possible alternative for users who want a managed queue rather than direct
Meta developer-app access. Use after native and Composio routes unless the
user explicitly chooses Buffer.

At the time of writing, Buffer's Free plan lists three connected channels,
10 scheduled posts per channel in the queue (slots refill after publication),
API access, and MCP access. Confirm current terms before recommending it.

- Connect the intended Facebook Page, Instagram professional account, and
  Threads account in Buffer (three channels consume all free slots).
- Check the current Buffer MCP capabilities, including what content/media can
  be sent, whether Threads reply chains are supported, and queue semantics.
- Do not equate a Buffer idea, draft or scheduled queue item with a live post.
  Preserve the underlying publish confirmation or channel URL.
- Human approval in this skill remains mandatory even if the provider offers
  its own optional approval or review flow.

Official references: https://buffer.com/pricing and https://buffer.com/mcp
