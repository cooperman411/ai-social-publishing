# Choose a Publishing Route

Check the operator's current tools first. For each selected account, verify whether a route can upload the chosen media, post now, schedule for a specified time, support any reply chain, and confirm the result. Report only the choices that fit the brief.

| Route | When It Fits | What Setup Adds |
| --- | --- | --- |
| Native connection | The assistant already has a tool that covers the requested account and actions | Verify the account and permissions. Use the host's connection screen if the operator needs to sign in. |
| Composio | The host can use Composio and the exact toolkit covers the missing action | Connect the assistant to Composio and authorize each required social account. Setup and limits vary by toolkit. |
| Buffer | The operator wants a managed publishing queue and the account and media are supported | Connect the channels in Buffer, then connect Buffer to the assistant. Check plan limits and whether the channel publishes automatically or sends a reminder. |
| Manual publishing | The operator wants to post directly or a tool cannot handle the format | Give the operator the final copy, file, credit, account, and due time. Ask for the live link or other confirmation afterward. |

Explain the tradeoff that matters to this run, including setup, current cost or limits, and any missing actions. Check native tools first, then Composio, then Buffer or manual publishing. Follow the operator's preference when it fits the required actions. Use the [Composio walkthrough](composio.md) or [Buffer setup guide](https://support.buffer.com/articles/connecting-buffer-to-automation-tools-and-ai-assistants-MMoXpjDEEo) when selected.

Confirm account identity and available operations through a read-only check. An account appearing in a list does not establish permission to publish. Confirm capability from the actual tool and account. Keep setup and draft review separate from permission to post.
