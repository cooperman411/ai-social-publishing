# Set Up Muse for Publishing

1. Open Muse’s connections and choose the accounts you want to use. Sign in through the service’s connection screen.
2. Ask Muse to show the name of each account and check what it can do there. Check the actions your plan needs, such as attaching an image, publishing, scheduling, or posting a Threads reply.
3. Check how Muse can confirm the result. A draft, a scheduled post, and a live post each have a different status.
4. Ask Muse for one draft. Check the copy, media, credit, account, and time. Approve that version when you’re ready to use it.

Meta describes the available connections in Muse settings. Check the account and action in your own session before relying on it. [Muse for Small Business](https://about.fb.com/news/2026/09/introducing-muse-small-business/)

## Post It Yourself

If you prefer to post directly or Muse lacks an action, ask it for the final copy, media, credit, account, and due time. Give Muse the live link or another confirmation after posting so it can update your history.
