# Connect Through Composio

Consider Composio when it covers an action you need and your Muse setup can use it. Check the exact account type, action, media format, and current limits. [Toolkits](https://docs.composio.dev/docs/toolkits) · [Pricing](https://composio.dev/pricing)

1. Check whether Muse has a working Composio connection. If it needs setup, follow the [Composio quickstart](https://docs.composio.dev/docs/quickstart) for the available integration.
2. Review which account and permissions the toolkit asks for. Sign in through the official [connection flow](https://docs.composio.dev/docs/authentication). Use the service’s secure setup if it asks for a custom app or credentials.
3. Ask Muse to verify the exact account and available actions. Check how you’ll confirm a scheduled or live post.
4. Return to the calendar and use the connection after approving the exact version and time.
