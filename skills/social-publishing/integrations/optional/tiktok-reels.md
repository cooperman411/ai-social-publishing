# Reuse a Vertical Video on TikTok

1. Choose a video you have permission to use and confirm the intended TikTok account.
2. Check the current upload format, scheduling options, and rights for the music on TikTok. Use the original file if it fits.
3. Adapt the caption for TikTok. Review the caption, video, audio, account, and time together.
4. Publish the approved version through a verified route or post it yourself. Record the TikTok result and live link separately.
