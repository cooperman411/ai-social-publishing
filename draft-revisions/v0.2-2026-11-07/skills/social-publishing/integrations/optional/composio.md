# Optional Bolt-On: Connect Through Composio

This is an optional bolt-on, not the core path. Use it only after Muse first works, and only when Composio covers a missing action in the operator's assistant. Check the [toolkit catalog](https://docs.composio.dev/docs/toolkits) for the exact destination and action. Confirm media support, scheduling or immediate publication, replies if needed, and how the tool returns status. Check [current pricing](https://composio.dev/pricing) and any limits that affect the plan.

1. Check whether the assistant already has a working Composio connection. If it does, identify the missing social accounts. If it does not, explain the host setup and guide the operator through the relevant [Composio quickstart](https://docs.composio.dev/docs/quickstart) or host integration. A hosted setup may already handle this connection.
2. Explain which social account and permissions are needed. With the operator's approval, use the host's connection flow or present the official [Connect Link](https://docs.composio.dev/docs/authentication) when supported. The operator signs in and approves the requested permissions in the service.
3. If a toolkit needs a custom app or credentials, explain the extra setup before proceeding. Use the service's secure configuration flow for credentials. Offer a simpler route when the operator prefers it.
4. Confirm the connection and verify the exact account with a read-only check. Recheck supported actions. Explain any gap, such as a tool that publishes now but cannot schedule or verify replies.
5. Return to the draft calendar. Use the connection for approved posts only.
