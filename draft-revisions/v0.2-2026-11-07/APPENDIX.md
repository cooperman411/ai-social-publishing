# Appendix: Optional Add-Ons

The core path is Muse, Facebook, Instagram, and Threads. You do not need anything on this page to start.

Add an item below only when you want it. Each item is optional. Each item keeps the same rules as the core path: you approve the exact version first, your own photos and video come first, and Muse posts only to a verified account.

Read the short note for each item, then follow the link if you want the full instructions.

## LinkedIn

LinkedIn is a site for work and business contacts. This add-on posts a version of an approved post to LinkedIn, to your personal profile or to a company Page you administer. A company Page is a public LinkedIn page for a business.

Use it when you want the same story on LinkedIn, in addition to Meta. It is a separate version, with its own approval. Muse adapts the copy for a work audience, and keeps the same fact and the same credit.

Full instructions: [LinkedIn](skills/social-publishing/integrations/optional/linkedin.md)

## TikTok Reels

This add-on reuses the same vertical video you already made for Instagram and Facebook Reels, and posts it to TikTok with its own caption and approval.

Use it only if you want to do video. If you want photos only, skip it. No new shoot is needed to add TikTok, and no new story is needed. Check the music separately for TikTok. A track cleared for Instagram may not be cleared for TikTok.

Full instructions: [TikTok Reels](skills/social-publishing/integrations/optional/tiktok-reels.md)

## Composio

Composio is a third-party service that connects an AI to social accounts. Use it only after the core path works, and only when Muse cannot reach an action you need, and Composio covers that exact action.

Use it when a needed action is missing in Muse. Check the current pricing and limits first. Muse still posts only approved versions.

Full instructions: [Composio](skills/social-publishing/integrations/optional/composio.md)

## Buffer

Buffer is a service that holds posts in a queue and sends them out on a schedule. A queue is a list of posts waiting to go out.

Use it when you want a managed queue instead of posting directly in Muse, and you accept its plan limits. Buffer has a free plan with limits on channels and scheduled posts. Check the current terms first. Approval in this skill is still required, even if Buffer offers its own review step.

Full instructions: [Buffer](skills/social-publishing/integrations/optional/buffer.md)

## Manual publishing

Manual publishing means you post it yourself, by hand. Muse gives you the approved copy, the file, the credit, the account, and the due time. You post it, then give Muse the live link so Muse can record it.

Use it when a tool cannot handle the format, or when you want to post directly. It is a good first step for a new channel.

Full instructions: see [Muse First](skills/social-publishing/integrations/muse-first.md), in the section on when the core path does not fit.

## Using this skill with another AI

This skill is plain text, so another AI can read it. It is not tested outside Muse, and there are no guarantees there.

Use this guide before you try it in another AI. It explains what transfers, what does not, and how to test one post first: do a read-only check, then a draft-only trial, then manual publishing. Do not assume another AI has the same connections, approvals, or publishing checks as Muse.

Full instructions: [Adapting to Another AI](skills/social-publishing/integrations/optional/adapting-to-other-ai.md)

## Other channels

You can add another channel the same way, for example X or YouTube. Add it as an optional add-on, with a verified account, an approved version adapted to that channel, and a recorded result. Do not add a channel to the core path without a tested Muse path for it.
